Part A

สัญญาณที่เข้า ADC เกิดขึ้นอย่างไร และหน้าตาเป็นอย่างไร

ADC ไม่ได้เห็น beat signal แบบเรดาร์ FMCW ทั่วไป มันเห็น chirp ที่ IF เต็มแถบ ซึ่งเป็นผลรวมของสามส่วน คือ TX leakage, echo จากฝน และ noise

A1แผนความถี่และ chirp ที่ส่งออก

\[ f_{LO} = 4\,N f_{ref} = 4 \times 1119 \times 7.68\ \text{MHz} = 34.37568\ \text{GHz}, \qquad f_{RF}(t) = f_{LO} + f_{IF}(t) \] \[ s(t) = e^{\,j\varphi(t)},\qquad \varphi(t) = \pi S t^2 - \pi B t,\qquad S = \frac{B}{T} = \frac{10\ \text{MHz}}{200\ \mu\text{s}} = 5\times10^{10}\ \text{Hz/s} \] \[ u_{DAC}(t) = \cos\!\big(2\pi f_{IF}\,t + \varphi(t)\big),\qquad f_{IF} = 37.5\ \text{GHz} - f_{LO} = 3.12432\ \text{GHz} \]

\(s(t)\) คือ complex envelope ของ chirp (ความถี่ขณะหนึ่งกวาดจาก −B/2 ถึง +B/2) ทุกสมการด้านล่างเขียนในรูป envelope นี้ ส่วนความถี่พาหะจะแยกเขียนเป็น \(e^{j2\pi f t}\)

A2สิ่งที่ antenna RX ได้รับ

ส่วนที่ 1
TX leakage เป็น chirp ที่รั่วตรงจาก antenna TX ไป RX ด้วย delay เกือบศูนย์ กำลัง = Pt/isolation = 20 − 40 = −20 dBm
ส่วนที่ 2
Echo จากฝน คือ chirp เดียวกันแต่ delay ตามระยะ แต่ละเซลล์ของฝนมีแอมพลิจูดสุ่มและความเร็วของตัวเอง รวมทั้งหมดได้ประมาณ −89 dBm
ส่วนที่ 3
Noise เกิดในวงจรรับเอง (ดู A3)
\[ r(t) = \underbrace{a_L\, s(t-\tau_L)}_{\text{leakage}} \;+\; \sum_{c}\underbrace{a_c[m]\; e^{-j2\pi f_c \tau_c}\; s(t-\tau_c)\, e^{\,j2\pi f_{D,c} t}}_{\text{rain cell } c} ,\qquad \tau_c = \frac{2R_c}{c_0},\quad f_{D,c} = \frac{2v_c}{\lambda} \] \[ |a_L|^2 = \frac{P_t}{\mathrm{ISO}},\qquad \mathrm{E}\,|a_c|^2 = \frac{P_t G_t G_r\,\theta\phi\,\pi^3 |K|^2 Z(R_c)\,\delta r}{512\ln 2\;\lambda^2 R_c^2 L}\;10^{-\mathrm{PIA}(R_c)/10} \]

สูตรที่สองคือ weather radar equation (Probert-Jones): กำลังจากฝนแปรตาม \(Z/R^2\) ไม่ใช่ \(1/R^4\) เพราะปริมาตรที่ลำคลื่นกวาดโตตาม \(R^2\) ส่วน \(a_c[m]\) เปลี่ยนจาก chirp ถึง chirp ตาม Doppler spectrum แบบ Gaussian (mean \(v\), width \(\sigma_v\)) โดยใช้วิธีของ Zrnić ส่วน PIA คือ attenuation สองทางจากฝนระหว่างทาง

A3Down-converter (ADMV1014), 90° hybrid และ noise

\[ z(t) = \sqrt{G}\; r(t)\, e^{\,j2\pi f_{IF} t} + n(t), \qquad z'(t) = \mu\, z(t) + \nu\, z^*(t), \qquad \mathrm{IRR} = \frac{|\mu|^2}{|\nu|^2} = 26.9\ \text{dB} \] \[ y(t) = \sqrt{2}\;\operatorname{Re}\{\mathcal{P}_+\, z'(t)\} \quad(\text{image-reject hybrid: upper sideband only}) \] \[ N_0 = k T_0\, F\, G + N_{0,ADC} \] \[ = (-144.0\ \text{dBm/Hz}) \oplus (-149.0\ \text{dBm/Hz}) = -142.8\ \text{dBm/Hz} \;\Rightarrow\; F_{eff} = 11.2\ \text{dB} \]

\(G\) = gain จาก antenna ถึง ADC (สมมติ 20 dB), \(F\) = NF ของ mixer (สมมติ 10 dB), \(\mu,\nu\) มาจาก IQ imbalance 0.5 dB / 4° และ \(\mathcal{P}_+\) หมายถึงเก็บเฉพาะความถี่บวก noise ของ ADC (NSD −150 dBFS/Hz) บวกเข้ามาอีกทำให้ NF รวมเพิ่มขึ้น 1.2 dB

A4หน้าตาของสัญญาณที่ขา ADC

รวม A1–A3 แล้วผ่าน BPF ที่เลือก Nyquist zone 3 (2.5–3.75 GHz) จะได้สัญญาณแอนะล็อกที่ ADC รับจริง:

\[ y(t) = \sqrt{2G}\;\operatorname{Re}\Big\{\Big[a_L\, s(t-\tau_L) + \sum_c a_c\, e^{-j2\pi f_c\tau_c}\, s(t-\tau_c)\Big]\, e^{\,j2\pi f_{IF} t}\Big\} + w(t) \]

กล่าวคือ ADC เห็นคลื่น cosine ที่ 3.124 GHz ความถี่เลื่อน ±5 MHz ตาม chirp แอมพลิจูดเกือบคงที่ 325 mV peak (มาจาก leakage) บนนั้นมี echo ฝนขนาดเล็กมากกับ noise ขี่อยู่ ใน time domain จึงแทบมองไม่เห็นฝนเลย

325 mV pkTX leakage (0.2 dBm) = 7,508 LSB
0.50 mV rmsnoise ทั้ง zone (−53 dBm) = 12 LSB
0.083 mV rmsecho ฝนทุกระดับรวมกัน (−68.6 dBm) = 1.9 LSB
4.2 µV rmsecho จาก bin 15 m ที่ 1 km (−94.6 dBm) = 0.1 LSB

A5RF-ADC: sampling ใน zone 3 และ quantization 14 บิต

เข้า

วิธี
sample ที่ \(f_s\) = 2.5 GS/s ซึ่งต่ำกว่า IF จงใจให้เกิด alias ลง zone 1 แล้ว quantize เป็น 14 บิต
ออก
int16 code ช่วง ±8192, 500,000 ตัวอย่างต่อ chirp (35 Gb/s ต่อช่อง) นี่คือ raw IF data ที่จะเก็บจาก ZCU216
\[ x[n] = \mathcal{Q}\{\,y(n/f_s)\,\},\qquad \Delta = \frac{2A_{FS}}{2^{14}} = 43.3\ \mu\text{V} \] \[ \text{SNR}_q = 6.02\times 14 + 1.76 = 86\ \text{dB} \] \[ f_{alias} = f_{IF} - (z-1)\frac{f_s}{2} = 3.12432 - 2.5 = 0.62432\ \text{GHz}\qquad(z = 3,\ \text{odd zone: not inverted}) \]

zone ที่ \(z = \lfloor f_{IF}/(f_s/2)\rfloor + 1 = 3\) เป็น zone คี่ สเปกตรัมจึงไม่กลับด้าน ถ้า chirp คร่อมขอบ zone (เช่นใช้ PLL 8.54 GHz ในโหมด 1 GHz) ส่วนที่ล้นเข้า zone 4 จะพับกลับด้านมาทับกัน

ข้อสังเกตสำคัญ ถ้า leakage แรงกว่านี้อีก 1 dB ADC จะ clip ทันที และ clipping ของสัญญาณที่แรงที่สุดจะสร้าง harmonic ที่กลบฝนทั้งหมด การวัด TX–RX isolation จริงจึงเป็นงานแรกที่ต้องทำ

A6SNR ของฝน 1 bin ในแต่ละขั้น

ติดตาม echo จาก bin 15 m ที่ 1 km (−94.6 dBm ที่ ADC) ผ่านทุกขั้น ทุกขั้นที่แคบแถบลงช่วยตัด noise ออก สัญญาณจึงค่อย ๆ โผล่ขึ้นจาก noise

\[ \text{SNR}_i = \frac{P_{bin}}{N_0\, B_{n,i}},\qquad B_{n}:\ 1.25\ \text{GHz} \to 54\ \text{MHz} \to 4.6\ \text{MHz} \to \frac{\text{ENBW}}{T} = 7.5\ \text{kHz} \]
