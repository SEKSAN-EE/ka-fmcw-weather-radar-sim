Ka-Band Weather Radar Simulation

Simulation ของสายรับทั้งหมด ตั้งแต่ echo จากฝนที่ antenna ไปจนถึง reflectivity, ความเร็ว, rain rate และลมแนวนอนจาก MIMO พร้อมเส้นทางสำหรับประมวลผลข้อมูลจริงจาก ZCU216

chirp → rain / cloud scene → TX leakage → ADMV1014 + hybrid → noise → BPF → 14-bit ADC → DDC → dechirp → range FFT → Doppler / pulse-pair → dBZ → attenuation → rain rate → MIMO angle FFT → wind
